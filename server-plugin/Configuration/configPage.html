Litefin Web Client Hosting

Open Litefin Web

The Litefin Web Client is hosted directly from your Jellyfin server at /litefin. It features hardware-accelerated playback with the Movi WebAssembly video player and ultra-fast navigation.

Supplies Cross-Origin-Opener-Policy and Cross-Origin-Embedder-Policy headers required for WebAssembly multi-threading (SharedArrayBuffer) and hardware video demuxing. Enabled by default.
Display name shown in the main server menu.
